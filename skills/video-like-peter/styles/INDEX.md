# Style library

Seventeen animation styles, each performing the same six second scene (a round character hops onto a platform, the title "Seven Skills" lands, a small celebration, exit to a seamless loop) on the shared engine in `_engine/` (`stage.js` deterministic `render(t)` loop, `scene.js` shared beats). Each `<slug>.md` is the recipe: palette, shape language, frame rate, technique with code, failure modes, reference queries.

Live demos and gallery: https://peterbu.com/showcase/skills/video-like-peter/styles/ (the author's site; to run a demo locally, serve the folder over HTTP).
